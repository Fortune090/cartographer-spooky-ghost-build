A modified xlive dll that gives new options in Cartographer's settings for Ghost debug views and Offset save states.

To build xlive.dll to your current install folder: download source and open Terminal/CMD from that folder. Run: .\build-cartographer.ps1 -DeployTo "yourFolderPathToCartographerHere"

This will backup your current xlive.dll and replace it with the Spooky Ghost Build version. Press the Pause/Break key in game to enter the Cartographer menu to access the Ghost Viewer settings.
